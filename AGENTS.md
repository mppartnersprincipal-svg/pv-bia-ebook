# Instruções do projeto — Codex

No início de cada nova sessão neste projeto, leia [MEMORIA.md](MEMORIA.md) antes de planejar ou alterar arquivos. Se o conteúdo já estiver no contexto, não é necessário relê-lo.

Esse arquivo é o resumo compartilhado com o Claude: trabalho concluído, decisões aprovadas, pendências e última verificação. Consulte a documentação detalhada e os materiais de referência apenas conforme a tarefa.

Após alterações relevantes, atualize `MEMORIA.md` com o estado realmente verificado. Mantenha o resumo curto, substituindo informações antigas em vez de acumular transcrições. As instruções atuais do usuário prevalecem sobre o histórico.
